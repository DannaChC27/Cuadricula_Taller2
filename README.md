# Cuadricula_Taller2
Un software realizado en Python que permite crear una cuadrícula y modificar unos círculos mediante diferentes coordenadas.

## ¿Qué hace?
* Crear una cuadrícula de tamaño mayor o igual a 8.
* Seleccionar coordenadas.
* Mostrar las coordenadas seleccionadas.
* Reiniciar la cuadrícula.
* Salir del programa.
